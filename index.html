Solving Quadratic Equations — Three Methods

Quadratic equations appear across all three Senior Secondary pathways in the CBC curriculum. Mastering all three solution methods — factorisation, the quadratic formula, and completing the square — is essential for both internal assessments and the KCSE examination.

Standard Form

ax² + bx + c = 0  (a ≠ 0)

A quadratic equation is any polynomial equation of degree 2. The term "quadratic" comes from the Latin quadratus, meaning "square." In the CBC curriculum, quadratic equations first appear in Grade 9 under the Algebra strand and deepen in Senior Secondary under Pure Mathematics. They model real-world situations such as projectile motion, profit optimisation, and area problems.

Method 01

Factorisation

Best used when the equation has small integer coefficients and factors neatly. Always check that the right-hand side equals zero before factorising.

Example: Solve x² + 5x + 6 = 0

  1. The equation is already in standard form (right side = 0).
  2. Find two numbers that multiply to c = 6 and add to b = 5. Those numbers are 2 and 3 (because 2 × 3 = 6, and 2 + 3 = 5).
  3. Rewrite as a product of two brackets: (x + 2)(x + 3) = 0
  4. Apply the Zero Product Property: if A × B = 0, then A = 0 or B = 0.
  5. Solve each factor: x + 2 = 0 → x = −2    x + 3 = 0 → x = −3
x = −2   or   x = −3

✓ Check: (−2)² + 5(−2) + 6 = 4 − 10 + 6 = 0 ✔

Method 02

Quadratic Formula

The most reliable method — works for every quadratic equation, including those that cannot be factorised over the integers.

Example: Solve 2x² − 4x − 6 = 0

  1. Identify the coefficients: a = 2, b = −4, c = −6
  2. Compute the discriminant: Δ = b² − 4ac = (−4)² − 4(2)(−6) = 16 + 48 = 64
  3. Since Δ > 0, there are two distinct real roots.
  4. Apply the formula: x = (−b ± √Δ) / 2a = (4 ± √64) / 4 = (4 ± 8) / 4
  5. x = (4 + 8)/4 = 12/4 = 3    or    x = (4 − 8)/4 = −4/4 = −1
x = 3   or   x = −1

✓ Check: 2(3)² − 4(3) − 6 = 18 − 12 − 6 = 0 ✔

Method 03

Completing the Square

This method transforms the quadratic into a perfect square, making it easy to solve. It also derives the quadratic formula and is essential for graphing parabolas.

Example: Solve x² + 6x + 5 = 0

  1. Move the constant to the right: x² + 6x = −5
  2. Take half of the coefficient of x: (6/2)² = 9
  3. Add 9 to both sides: x² + 6x + 9 = −5 + 9 = 4
  4. Write the left side as a perfect square: (x + 3)² = 4
  5. Take square roots: x + 3 = ±2
  6. x = −3 + 2 = −1    or    x = −3 − 2 = −5
x = −1   or   x = −5

✓ Check: (−1)² + 6(−1) + 5 = 1 − 6 + 5 = 0 ✔

Understanding the Discriminant (Δ = b² − 4ac)
Δ > 0 Two distinct real roots e.g. x² − 5x + 6 = 0 → x = 2, 3
Δ = 0 One repeated real root e.g. x² − 4x + 4 = 0 → x = 2 (twice)
Δ < 0 No real roots (complex roots) e.g. x² + x + 1 = 0 → complex roots
⚠ Common Errors to Avoid
  • Not rearranging to standard form (= 0) before solving
  • Sign errors when substituting negative values of b into the formula
  • Writing only one solution when ± gives two answers
  • In completing the square, forgetting to add the same value to both sides
  • Confusing "no real roots" (Δ < 0) with "no solution" — complex roots still exist

Learning Pathway

How to Use This Site Effectively

A recommended study pathway that mirrors how CBC competencies are built — from foundational understanding through to examination readiness.

  1. 1

    Read the Lesson

    Start with the theory section of each topic page. Every concept is explained in plain English with real-world context. Understanding why a rule works is the CBC approach — not just memorising formulas.

  2. 2

    Study the Worked Examples

    Each lesson contains multiple fully worked examples that mirror KCSE and Senior Secondary exam questions. Read each step carefully — notice how each line follows logically from the one before it.

  3. 3

    Attempt Practice Problems

    Visit the Practice Problems page and attempt questions on the topic you just studied. Close your notes and work independently — this is how real learning happens.

  4. 4

    Check Your Work

    Review your answers and identify where you went wrong. Common errors are highlighted in every lesson. Understanding your mistake is more valuable than getting the answer right on the first try.

  5. 5

    Ask Mwalimu if Stuck

    If you are stuck on a concept or a specific question, post it on Ask Mwalimu. Mwalimu Ronny responds with a clear, step-by-step explanation tailored to your question.
