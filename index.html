📐 Today's Free Math Lesson: Solving Quadratic Equations

Complete step-by-step guide with examples for high school students

What is a Quadratic Equation?

A quadratic equation is any equation that can be written in the form:

ax² + bx + c = 0

where a, b, and c are constants, and a ≠ 0

Method 1: Factoring (When Possible)

Example 1: Solve x² + 5x + 6 = 0

Step 1: Find two numbers that multiply to give c (6) and add to give b (5)

Numbers: 2 and 3 because 2 × 3 = 6 and 2 + 3 = 5

Step 2: Rewrite as: (x + 2)(x + 3) = 0

Step 3: Set each factor to zero: x + 2 = 0 or x + 3 = 0

Step 4: Solve: x = -2 or x = -3

Answer: x = -2, x = -3

Method 2: Quadratic Formula (Works for All)

x = [-b ± √(b² - 4ac)] / 2a

Example 2: Solve 2x² - 4x - 6 = 0

Step 1: Identify a = 2, b = -4, c = -6

Step 2: Calculate discriminant: b² - 4ac = (-4)² - 4(2)(-6)

= 16 + 48 = 64

Step 3: Apply formula: x = [4 ± √64] / 4

= [4 ± 8] / 4

Step 4: Solve: x = (4 + 8)/4 = 3 or x = (4 - 8)/4 = -1

Answer: x = 3, x = -1

Common Mistakes to Avoid

  • ❌ Forgetting to set the equation to zero first
  • ❌ Incorrect signs when using quadratic formula
  • ❌ Forgetting the ± symbol gives two solutions
  • ❌ Not checking if factoring is possible before using formula

Practice Problems (Try These Yourself)

  1. x² + 7x + 12 = 0 (Answer: x = -3, x = -4)
  2. x² - 5x + 6 = 0 (Answer: x = 2, x = 3)
  3. 2x² + 5x - 3 = 0 (Answer: x = 1/2, x = -3)
  4. 3x² - 2x - 5 = 0 (Answer: x = -1, x = 5/3)

🔢 Algebra Fundamentals: Working with Variables

Simplifying Algebraic Expressions

Rule: Combine like terms (terms with the same variable and exponent)

Example 1: Simplify 3x + 5y - 2x + 3y

Step 1: Group like terms: (3x - 2x) + (5y + 3y)

Step 2: Combine: x + 8y

Answer: x + 8y

Example 2: Simplify 4a² + 3a - 2a² + 5a - 7

Step 1: Group like terms: (4a² - 2a²) + (3a + 5a) - 7

Step 2: Combine: 2a² + 8a - 7

Answer: 2a² + 8a - 7

Solving Linear Equations

Example: Solve 2x + 5 = 13

Step 1: Subtract 5 from both sides: 2x = 8

Step 2: Divide both sides by 2: x = 4

Answer: x = 4

📐 Trigonometry: Sine, Cosine, and Tangent Explained

Right Triangle Ratios

For a right triangle with angle θ:

  • sin θ = opposite / hypotenuse
  • cos θ = adjacent / hypotenuse
  • tan θ = opposite / adjacent

Common Angle Values

Angle θ sin θ cos θ tan θ
0° 0 1 0
30° 1/2 √3/2 1/√3
45° √2/2 √2/2 1
60° √3/2 1/2 √3
90° 1 0 undefined

Example Problem

Find sin(30°), cos(30°), and tan(30°)

From the table above:

sin(30°) = 1/2 = 0.5

cos(30°) = √3/2 ≈ 0.866

tan(30°) = 1/√3 ≈ 0.577

📈 Calculus: Introduction to Differentiation

The Power Rule

If f(x) = xⁿ, then f'(x) = n·xⁿ⁻¹

Examples

Example 1: Find derivative of f(x) = x⁴

f'(x) = 4x³

Example 2: Find derivative of f(x) = 3x²

f'(x) = 3 × 2x = 6x

Example 3: Find derivative of f(x) = 5x³ + 2x² - 7x + 4

f'(x) = 15x² + 4x - 7
