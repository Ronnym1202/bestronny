Solving Quadratic Equations

One of the most important topics in secondary mathematics — covered with three distinct methods.

Standard Form

ax² + bx + c = 0  (a ≠ 0)

01

Factorisation

Example: x² + 5x + 6 = 0

  1. Find two numbers multiplying to 6 and adding to 5 → 2 & 3
  2. Rewrite: (x + 2)(x + 3) = 0
  3. x + 2 = 0  or  x + 3 = 0
x = −2  or  x = −3
02

Quadratic Formula

Example: 2x² − 4x − 6 = 0

  1. a = 2, b = −4, c = −6
  2. Discriminant: b²−4ac = 16+48 = 64
  3. x = (4 ± √64) / 4 = (4 ± 8) / 4
x = 3  or  x = −1
03

Completing the Square

Example: x² + 6x + 5 = 0

  1. Move constant: x² + 6x = −5
  2. Add (6/2)² = 9: (x+3)² = 4
  3. x + 3 = ±2
x = −1  or  x = −5
⚠ Common Errors
  • Forgetting to set the equation to zero first
  • Sign errors when substituting into the formula
  • Forgetting that ± produces two solutions
