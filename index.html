Solving Quadratic Equations: Complete Guide

Master factoring, the quadratic formula, and discriminant analysis

What is a Quadratic Equation?

Any equation that can be written in standard form:

ax² + bx + c = 0

where a, b, c are real constants and a ≠ 0

01 Factoring Method

Example: x² + 5x + 6 = 0

  1. Find two numbers that multiply to 6 and add to 5 → 2 and 3
  2. Rewrite as: (x + 2)(x + 3) = 0
  3. Set each factor to zero: x + 2 = 0 or x + 3 = 0
  4. Solve: x = −2 or x = −3
Answer: x = −2, x = −3

02 Quadratic Formula

x = [−b ± √(b² − 4ac)] / 2a

Example: 2x² − 4x − 6 = 0

  1. Identify: a = 2, b = −4, c = −6
  2. Discriminant: b² − 4ac = 16 + 48 = 64
  3. x = [4 ± √64] / 4 = [4 ± 8] / 4
  4. Solve: x = 3 or x = −1
Answer: x = 3, x = −1

⚠ Common Mistakes to Avoid

  • Forgetting to set the equation to zero first
  • Incorrect signs when substituting into the formula
  • Forgetting that ± gives two separate solutions
  • Not checking whether factoring is possible first
