# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest (live on Netlify) | ✅ |
| Older deployments | ❌ |

Only the current live deployment at [https://bestronny.netlify.app](https://bestronny.netlify.app) receives security attention. Older or cached deployments are not maintained.

---

## Scope

This policy covers the **Ronny Best Mathematics** web platform, including:

- All pages under `bestronny.netlify.app`
- Client-side JavaScript (progress tracking, search, filtering)
- Any form inputs (contact, Ask Mwalimu)

**Out of scope:**

- Third-party services (Google AdSense, Google Fonts, Netlify infrastructure)
- Browser-level vulnerabilities unrelated to this site's code

---

## Reporting a Vulnerability

If you discover a security vulnerability on **Ronny Best Mathematics**, please report it responsibly and privately. **Do NOT open a public GitHub issue** for security vulnerabilities, as this could expose students and visitors to risk before a fix is in place.

### How to Report

- **Email:** [ronnymwenda89@gmail.com](mailto:ronnymwenda89@gmail.com)
- **Subject line:** `[SECURITY] Ronny Best Mathematics — <brief description>`

### What to Include

Please provide as much detail as possible:

- A clear description of the vulnerability
- Step-by-step instructions to reproduce it
- The potential impact on users or the platform
- Your recommended fix or mitigation (optional but appreciated)

### What to Expect

| Stage | Timeframe |
| ----- | --------- |
| Initial acknowledgement | Within 48–72 hours |
| Investigation update | Within 7 days |
| Resolution (if accepted) | As soon as reasonably possible |
| Explanation (if declined) | With the closing response |

- **If accepted:** The vulnerability will be fixed promptly and you will be credited in the fix (unless you prefer to remain anonymous).
- **If declined:** You will receive a clear explanation of why the report was not actioned.

---

## Responsible Disclosure

We ask that you:

- Give us reasonable time to investigate and fix the issue before any public disclosure
- Avoid accessing, modifying, or deleting data that does not belong to you
- Do not disrupt the platform's availability or performance during testing

We commit to handling all reports professionally, promptly, and with respect for your effort.
