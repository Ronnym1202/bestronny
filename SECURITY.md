# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest (live on Netlify) | ✅ |
| Older deployments | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability on **Ronny Best Mathematics**
(https://bestronny.netlify.app), please report it responsibly.

### How to Report
- **Email:** ronnymwenda89@gmail.com
- **Do NOT** open a public GitHub issue for security vulnerabilities

### What to Include
- Description of the vulnerability
- Steps to reproduce it
- Potential impact

### What to Expect
- **Response time:** Within 48–72 hours
- **Updates:** You will be notified as the issue is investigated
- **If accepted:** The vulnerability will be fixed and you will be credited
- **If declined:** You will receive a clear explanation why

Thank you for helping keep this platform safe for students! 🙏
