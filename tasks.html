Sample Practice Problems

Differentiation Example

Find the derivative of: ( f(x) = 3x^4 - 2x^2 + 5x - 7 )

Solution: Using power rule: ( f'(x) = 12x^3 - 4x + 5 )

Step-by-step:

  1. ( d/dx(3x^4) = 3 dot 4x^3 = 12x^3 )
  2. ( d/dx(-2x^2) = -2 dot 2x = -4x )
  3. ( d/dx(5x) = 5 )
  4. ( d/dx(-7) = 0 )
  5. Combine: ( f'(x) = 12x^3 - 4x + 5 )

Matrix Example

Find the determinant of: \( \begin{bmatrix} 3 & 2 \\ 1 & 4 \end{bmatrix} \)

Solution: \( (3 \times 4) - (2 \times 1) = 12 - 2 = 10 \)
