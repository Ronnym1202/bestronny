(a). Trigonometry Ratios From a Right-angled Triangle

NB/ x represents angle theta
  • Sin x=Opposite/Hypotenuse
  • Cos x=Adjacent/Hypotenuse
  • Tan x=Opposite/Adjacent

  • Sec x=1/Cos x
  • Cosec x=1/Sin x
  • Cot x=1/Tan x

Detailed Explanation:

In a right triangle with angle x, the side opposite to x is called the "opposite" side, the side next to x (that's not the hypotenuse) is the "adjacent" side, and the longest side is the "hypotenuse". These ratios form the foundation of all trigonometry.

Examples:

Example 1: In a right triangle, opposite = 3, hypotenuse = 5. Find sin x.
Solution: sin x = opposite/hypotenuse = 3/5 = 0.6

Example 2: In a right triangle, adjacent = 4, hypotenuse = 5. Find cos x.
Solution: cos x = adjacent/hypotenuse = 4/5 = 0.8

Example 3: In a right triangle, opposite = 3, adjacent = 4. Find tan x.
Solution: tan x = opposite/adjacent = 3/4 = 0.75

(b). General Triangles

  1. Sine Rule: a/Sin A = b/Sin B = c/Sin C = 2R (Where R is the circum radius)

  2. Cosine Rule: a² = b²+c² - 2bcCos A

  3. Area of Triangle: 1/2bh = 1/2abSin C = sqrt of s(s-a)(s-b)(s-c), Where s = 1/2(a+b+c)

  4. Tan 1/2A = SQRT of (s-b)(s-c)/s(s-a)

Detailed Explanation:

The Sine Rule relates sides of any triangle to the sines of their opposite angles. The Cosine Rule generalizes Pythagoras theorem for non-right triangles. Heron's formula (s(s-a)(s-b)(s-c)) calculates area using only side lengths.

Examples:

Example 1 (Sine Rule): In triangle ABC, a=7, A=30°, B=45°. Find b.
Solution: a/sinA = b/sinB → 7/sin30° = b/sin45° → 7/0.5 = b/0.7071 → b = 14 × 0.7071 = 9.9

Example 2 (Cosine Rule): In triangle ABC, b=5, c=7, A=60°. Find a.
Solution: a² = b²+c²-2bc cosA = 25+49-2×5×7×cos60° = 74-70×0.5 = 74-35 = 39 → a = √39 ≈ 6.24

Example 3 (Area): Triangle sides a=5, b=6, c=7. Find area.
Solution: s = (5+6+7)/2 = 9, Area = √[9(9-5)(9-6)(9-7)] = √[9×4×3×2] = √216 = 6√6 ≈ 14.7

(c). Identities

  • Sin²x + Cos²x = AB² + BC²/AC² = 1

  • 1 + Tan²x = Sec²x

  • Cot²x + 1 = Cosec²x

Detailed Explanation:

The Pythagorean identity sin²x + cos²x = 1 comes directly from the Pythagorean theorem applied to the unit circle. The other identities can be derived by dividing this identity by cos²x or sin²x.

Examples:

Example 1: If sin x = 3/5, find cos x.
Solution: sin²x + cos²x = 1 → (9/25) + cos²x = 1 → cos²x = 16/25 → cos x = ±4/5

Example 2: If tan x = 4/3, find sec x.
Solution: 1 + tan²x = sec²x → 1 + (16/9) = sec²x → 25/9 = sec²x → sec x = ±5/3

Example 3: If cot x = 2, find cosec x.
Solution: cot²x + 1 = cosec²x → 4 + 1 = cosec²x → cosec²x = 5 → cosec x = ±√5

Trigonometric Ratios

In a right–angled triangle:

  • sin x = opposite / hypotenuse
  • cos x = adjacent / hypotenuse
  • tan x = opposite / adjacent
  • cosec x = 1/sin x
  • sec x = 1/cos x
  • cot x = 1/tan x

Trigonometric Identities

  • sin²x + cos²x = 1
  • 1 + tan²x = sec²x
  • 1 + cot²x = cosec²x
  • sin(−x) = −sin x
  • cos(−x) = cos x
  • tan(−x) = −tan x

Compound Angle Formulas

  • sin(a ± b) = sin a cos b ± cos a sin b
  • cos(a ± b) = cos a cos b ∓ sin a sin b
  • tan(a ± b) = (tan a ± tan b)/(1 ∓ tan a tan b)

Examples:

Example 1: Find sin(15°) using sin(45°-30°)
Solution: sin(45°-30°) = sin45°cos30° - cos45°sin30° = (√2/2)(√3/2) - (√2/2)(1/2) = (√6-√2)/4 ≈ 0.2588

Example 2: Find cos(75°) using cos(45°+30°)
Solution: cos(45°+30°) = cos45°cos30° - sin45°sin30° = (√2/2)(√3/2) - (√2/2)(1/2) = (√6-√2)/4 ≈ 0.2588

Example 3: Find tan(105°) using tan(60°+45°)
Solution: tan(60°+45°) = (tan60°+tan45°)/(1-tan60°tan45°) = (√3+1)/(1-√3×1) = (√3+1)/(1-√3) ≈ -3.732

HALF-ANGLE FORMULAS

  • sin A/2 = ±√1-cos A/2
  • cos A/2 = ±√1+cos A/2
  • tan A/2 = 1 - cos A/sin A = sin A/1+cos A

Examples:

Example 1: Find sin 15° using half-angle (30°)
Solution: sin(30°/2) = √[(1-cos30°)/2] = √[(1-√3/2)/2] = √[(2-√3)/4] = √(2-√3)/2 ≈ 0.2588

Example 2: Find cos 22.5° using half-angle (45°)
Solution: cos(45°/2) = √[(1+cos45°)/2] = √[(1+√2/2)/2] = √[(2+√2)/4] = √(2+√2)/2 ≈ 0.9239

Example 3: Find tan 15° using half-angle formula
Solution: tan(30°/2) = (1-cos30°)/sin30° = (1-√3/2)/(1/2) = 2-√3 ≈ 0.2679

PRODUCT-TO-SUM FORMULAS

  • sinAsinB=1/2[cos(A−B)−cos(A+B)]
  • cosAcosB=1/2[cos(A−B)+cos(A+B)]
  • cosAcosB=1/2[cos(A−B)+cos(A+B)]

Examples:

Example 1: Express sin30°sin60° as sum/difference
Solution: sin30°sin60° = ½[cos(30°-60°) - cos(30°+60°)] = ½[cos(-30°) - cos90°] = ½[√3/2 - 0] = √3/4

Example 2: Express cos45°cos15° as sum/difference
Solution: cos45°cos15° = ½[cos(45°-15°) + cos(45°+15°)] = ½[cos30° + cos60°] = ½[√3/2 + ½] = (√3+1)/4

Example 3: Express sin75°cos15° as sum/difference
Solution: sinAcosB = ½[sin(A+B) + sin(A-B)] = ½[sin90° + sin60°] = ½[1 + √3/2] = (2+√3)/4

Applications

  • Heights and distances
  • Navigation and bearing
  • Simple harmonic motion

Examples:

Example 1 (Height): From 50m away, angle to top of tree is 30°. Find height.
Solution: tan30° = height/50 → height = 50 × tan30° = 50 × 1/√3 ≈ 28.87m

Example 2 (Navigation): Ship sails 10km east, then 5km northeast (45°). Find distance from start.
Solution: Use law of cosines: d² = 10² + 5² - 2×10×5×cos135° = 100+25-100×(-0.7071) = 125+70.71 = 195.71 → d ≈ 13.99km

Example 3 (SHM): Particle's displacement: x = 5sin(2t+π/4). Find velocity at t=0.
Solution: v = dx/dt = 10cos(2t+π/4) → at t=0, v = 10cos(π/4) = 10×√2/2 = 5√2 ≈ 7.07 units/s

Algebra

(a). Quadratic Equation

  • ax² + bx + c = 0
  • Roots: x = (-b ± √(b² − 4ac)) / (2a)
  • Nature of roots depends on discriminant Δ = b² − 4ac

Detailed Explanation:

The quadratic formula solves any quadratic equation. The discriminant (Δ) determines the nature of roots: Δ>0 (two real distinct roots), Δ=0 (one real repeated root), Δ<0 (two complex conjugate roots).

Examples:

Example 1: Solve x² - 5x + 6 = 0
Solution: a=1, b=-5, c=6 → Δ = 25-24=1 → x = (5±1)/2 → x=3 or x=2

Example 2: Solve 2x² + 4x + 2 = 0
Solution: a=2, b=4, c=2 → Δ = 16-16=0 → x = (-4±0)/4 = -1 (repeated root)

Example 3: Solve x² + 2x + 5 = 0
Solution: a=1, b=2, c=5 → Δ = 4-20=-16 → x = (-2±4i)/2 = -1±2i (complex roots)

(b). Quadratic Identities

  1. (a + b)² = a² + 2ab + b²

  2. (a - b)² =a² - 2ab + b²

  3. (a + b)(a - b) = a² - b²

Examples:

Example 1: Expand (3x+4)²
Solution: (3x)² + 2(3x)(4) + 4² = 9x² + 24x + 16

Example 2: Expand (2y-5)²
Solution: (2y)² - 2(2y)(5) + 5² = 4y² - 20y + 25

Example 3: Multiply (7a+3b)(7a-3b)
Solution: (7a)² - (3b)² = 49a² - 9b²

(c). Series

(i). Arithmetic series
  • Sn = n/2{2a + (n - 1)d} or Sn = n/2(a + l)

  • Where a is the first term, d is the common difference, l is the last term and n is the number of terms.


(ii). Geometric Series
  • Sn = a(rn - 1)/r - 1 , Where r > 1

  • Sn = a(1 - rn)/1 - r, Where r is less than 1

Examples:

Example 1 (Arithmetic): Find sum of first 20 terms: 3, 7, 11, 15, ...
Solution: a=3, d=4, n=20 → S₂₀ = 20/2[2×3 + (20-1)×4] = 10[6+76] = 10×82 = 820

Example 2 (Geometric): Find sum of first 6 terms: 2, 6, 18, 54, ...
Solution: a=2, r=3, n=6 → S₆ = 2(3⁶-1)/(3-1) = 2(729-1)/2 = 728

Example 3 (Infinite Geometric): Find sum: 1 + ½ + ¼ + ⅛ + ...
Solution: a=1, r=½ → S = a/(1-r) = 1/(1-½) = 2

CIRCLE

1. Standard Form
  • (x - h)2 + (y - k)2 = r2
  • Center: (h , k)
  • Radius: r
2. General Form
  • x2 + y2 + 2gx + 2fy + c = 0
  • Center: (-g, _f)
  • Radius: r = √g2 + f2 - c
3. Diameter Form
  • (x - x1)(x - x2) + (y - y1)(y - y2) = 0
4. Parametric Form
  • x = h + rcos θ
  • y = k + rsin θ
5. Tangent to Circle

At point (x1 , y1)

  • xx1 + yy1 + g(x + x1) + f(y + y1) + c = 0

Examples:

Example 1: Find center and radius of (x-2)²+(y+3)²=16
Solution: Center=(2,-3), Radius=4

Example 2: Convert x²+y²-4x+6y+9=0 to standard form
Solution: Complete squares: (x²-4x+4)+(y²+6y+9)=-9+4+9 → (x-2)²+(y+3)²=4

Example 3: Find tangent to x²+y²=25 at (3,4)
Solution: Formula: 3x+4y=25 → 3x+4y-25=0

Solution: a=4, c=5 → b=√(25-16)=3 → x²/16 - y²/9 = 1

Solution: For x=3: 9/4 - y²/9=1 → y²/9=9/4-1=5/4 → y=±3√5/2. Use tangent formula.

Statistics

Measures of Central Tendency

These are values that describe the center of a data set:

  • Mean: The average of all numbers. Formula: Mean = (Σx) / n
  • Median: The middle value when data is ordered. For odd n: middle value; for even n: average of two middle values.
  • Mode: The most frequently occurring value in a data set.

Example: For data [2, 4, 4, 6, 8]: Mean = (2+4+4+6+8)/5 = 4.8, Median = 4, Mode = 4.

Examples:

Example 1: Data: 5, 7, 7, 8, 9, 10, 12. Find mean, median, mode.
Solution: Mean=(5+7+7+8+9+10+12)/7=58/7≈8.29. Median=8 (4th value). Mode=7.

Example 2: Data: 3, 5, 7, 9, 11, 13. Find median.
Solution: Even number: median=(7+9)/2=8.

Example 3: Data: 4, 4, 5, 5, 5, 6, 6, 7. Find mode.
Solution: 5 occurs 3 times → mode=5.

Measures of Dispersion

These measure how spread out the data is:

  • Range: Difference between highest and lowest values.
  • Variance: Average of squared differences from mean. σ² = Σ(x - μ)²/n
  • Standard Deviation: Square root of variance. σ = √[Σ(x - μ)²/n]
  • Interquartile Range (IQR): Difference between Q3 (75th percentile) and Q1 (25th percentile).

Examples:

Example 1: Data: 2,4,6,8,10. Find range and variance.
Solution: Range=10-2=8. Mean=6. Variance=[(2-6)²+(4-6)²+(6-6)²+(8-6)²+(10-6)²]/5=40/5=8.

Example 2: Data: 1,3,5,7,9. Find standard deviation.
Solution: Mean=5. Variance=[16+4+0+4+16]/5=40/5=8. σ=√8≈2.83.

Example 3: Data: 10,20,30,40,50,60,70. Find IQR.
Solution: Q1=20, Q3=50 → IQR=50-20=30.

Probability Basics

Probability measures how likely an event is to occur (0 to 1):

  • Mutually Exclusive Events: Cannot occur together. P(A∪B) = P(A) + P(B)
  • Independent Events: Occurrence of one doesn't affect the other. P(A∩B) = P(A) × P(B)
  • Conditional Probability: Probability of A given B. P(A|B) = P(A∩B) / P(B)

Examples:

Example 1: P(A)=0.3, P(B)=0.4, A and B mutually exclusive. Find P(A∪B).
Solution: P(A∪B)=0.3+0.4=0.7.

Example 2: Two independent events: P(A)=0.5, P(B)=0.6. Find P(A∩B).
Solution: P(A∩B)=0.5×0.6=0.3.

Example 3: P(A∩B)=0.2, P(B)=0.5. Find P(A|B).
Solution: P(A|B)=0.2/0.5=0.4.

Differentiation

Definition

Differentiation is the process of finding the derivative of a function. The derivative represents the instantaneous rate of change.

Basic Rules

  • Power Rule: d/dx (xⁿ) = n xⁿ⁻¹
  • Product Rule: (uv)' = u'v + uv'
  • Quotient Rule: (u/v)' = (u'v − uv') / v²
  • Chain Rule: d/dx f(g(x)) = f’(g(x))·g’(x)

Examples:

Example 1 (Power): d/dx(x⁵) = 5x⁴

Example 2 (Product): Differentiate f(x)=x²sinx
Solution: f'(x)=2x sinx + x² cosx

Example 3 (Quotient): Differentiate f(x)=(x+1)/(x-1)
Solution: f'(x)=[(1)(x-1)-(x+1)(1)]/(x-1)² = (x-1-x-1)/(x-1)² = -2/(x-1)²

Trigonometric Derivatives

  • d/dx(sin x) = cos x
  • d/dx(cos x) = −sin x
  • d/dx(tan x) = sec²x

Examples:

Example 1: d/dx(sin3x)=3cos3x (chain rule)

Example 2: d/dx(cos²x)=2cosx×(-sinx)=-2sinxcosx=-sin2x

Example 3: d/dx(tan(x²))=sec²(x²)×2x=2x sec²(x²)

Exponential & Logarithmic Derivatives

  • d/dx(eˣ) = eˣ
  • d/dx(ln x) = 1/x
  • d/dx(aˣ) = aˣ ln(a)

Examples:

Example 1: d/dx(e2x)=2e2x

Example 2: d/dx(ln(3x))=1/(3x)×3=1/x

Example 3: d/dx(2ˣ)=2ˣ ln2

Applications

  • Finding maxima and minima
  • Rates of change
  • Newton–Raphson method
  • Curve sketching

Examples:

Example 1 (Max/Min): Find extrema of f(x)=x³-3x+2
Solution: f'(x)=3x²-3=0 → x=±1. f''(x)=6x. f''(1)=6>0 → min at x=1. f''(-1)=-6<0 → max at x=-1.

Example 2 (Rate): Radius increasing at 3cm/s. Find rate of area change when r=5cm.
Solution: A=πr², dA/dt=2πr dr/dt=2π×5×3=30π cm²/s

Example 3 (Newton): Approximate √2 using x²-2=0, start x=1.5
Solution: x₁=1.5-(1.5²-2)/(2×1.5)=1.5-(2.25-2)/3=1.5-0.25/3=1.4167

Integration

Definition

Integration is the process of finding the antiderivative or area under a curve.

Basic Integrals

  • ∫ xⁿ dx = xⁿ⁺¹ / (n+1) + C
  • ∫ eˣ dx = eˣ + C
  • ∫ 1/x dx = ln|x| + C

Examples:

Example 1: ∫x⁴ dx = x⁵/5 + C

Example 2: ∫e3x dx = (1/3)e3x + C

Example 3: ∫(1/(2x)) dx = (1/2)ln|x| + C

Methods of Integration

  • Substitution
  • Integration by Parts
  • Partial Fractions
  • Trigonometric Integrals

Examples:

Example 1 (Substitution): ∫2x(x²+1)³ dx
Solution: Let u=x²+1, du=2xdx → ∫u³ du = u⁴/4+C = (x²+1)⁴/4+C

Example 2 (By Parts): ∫x eˣ dx
Solution: Let u=x, dv=eˣdx → du=dx, v=eˣ → ∫ = xeˣ - ∫eˣ dx = xeˣ - eˣ + C

Example 3 (Partial Fractions): ∫(3x+2)/((x-1)(x+2)) dx
Solution: Decompose to A/(x-1)+B/(x+2). Find A=1, B=2 → ∫=ln|x-1|+2ln|x+2|+C

Applications

  • Area under curves
  • Volume of rotation
  • Average value of a function

Examples:

Example 1 (Area): Find area between y=x² and y=0 from x=0 to 2
Solution: ∫₀² x² dx = [x³/3]₀² = 8/3

Example 2 (Volume): Volume by rotating y=√x from x=0 to 4 about x-axis
Solution: V=π∫₀⁴ (√x)² dx = π∫₀⁴ x dx = π[x²/2]₀⁴ = π×8 = 8π

Example 3 (Average): Average value of sinx on [0,π]
Solution: (1/(π-0))∫₀^π sinx dx = (1/π)[-cosx]₀^π = (1/π)(1+1)=2/π≈0.6366

Vectors

Vector Basics

A vector has both magnitude (length) and direction. Represented as v = (x, y, z) or v = ai + bj + ck.

Magnitude: |v| = √(x² + y² + z²)

Unit Vector: û = v / |v| (has magnitude 1)

Examples:

Example 1: Find magnitude of v = (3,4)
Solution: |v| = √(3²+4²) = √25 = 5

Example 2: Find unit vector in direction of (1,1,1)
Solution: |v| = √3 → û = (1/√3, 1/√3, 1/√3)

Example 3: If v = 2i+3j-k, find |v|
Solution: |v| = √(4+9+1) = √14 ≈ 3.74

Vector Operations

  • Addition: (a,b) + (c,d) = (a+c, b+d)
  • Scalar Multiplication: k(a,b) = (ka, kb)
  • Dot Product: a·b = |a||b|cosθ = a₁b₁ + a₂b₂ + a₃b₃
  • Cross Product: a×b = |a||b|sinθ n̂ (results in perpendicular vector)

Applications: Physics (force, velocity), Computer Graphics, Engineering.

Examples:

Example 1 (Dot): (1,2)·(3,4)=1×3+2×4=3+8=11

Example 2 (Dot angle): Find angle between (1,0) and (0,1)
Solution: cosθ = (1×0+0×1)/(1×1) = 0 → θ=90°

Example 3 (Cross): i×j = k, j×k = i, k×i = j

Matrices

What is a Matrix?

A matrix is a rectangular array of numbers arranged in rows and columns. Represented as A = [aij] where i = row, j = column.

Example 2×3 matrix: A = \begin{bmatrix} 1 & 3 & 5 \\ 2 & 4 & 6 \end{bmatrix}

Matrix Types

  • Square Matrix: Same number of rows and columns (n×n)
  • Diagonal Matrix: All non-diagonal elements are zero
  • Identity Matrix (I): Diagonal matrix with all 1's on diagonal
  • Zero/Null Matrix: All elements are zero
  • Symmetric Matrix: A = AT (equal to its transpose)

Matrix Operations

  • Addition/Subtraction: Matrices must have same dimensions. Add corresponding elements.
  • Multiplication: For A (m×n) × B (n×p), result is (m×p). Not commutative: AB ≠ BA
  • Transpose (AT): Rows become columns and vice versa
  • Determinant: Scalar value for square matrices. For 2×2: det = ad - bc
  • Inverse (A-1): Only for square matrices with non-zero determinant. AA-1 = I

Example 2×2 determinant: For matrix \begin{bmatrix} a & b \\ c & d \end{bmatrix} , det = ad - bc

Examples:

Example 1 (Add): [1 2; 3 4] + [5 6; 7 8] = [6 8; 10 12]

Example 2 (Multiply): [1 2; 3 4]×[5 6; 7 8] = [1×5+2×7, 1×6+2×8; 3×5+4×7, 3×6+4×8] = [19 22; 43 50]

Example 3 (Determinant): det([2 3; 1 4]) = 2×4 - 3×1 = 8-3=5

Applications of Matrices

  • Solving Systems of Equations: Using Gaussian elimination or inverse matrices
  • Computer Graphics: Transformations (rotation, scaling, translation)
  • Economics: Input-output models, Markov chains
  • Physics/Engineering: Stress tensors, quantum mechanics

Examples:

Example 1 (System): Solve 2x+3y=8, 4x-y=6 using matrices
Solution: [2 3; 4 -1][x;y]=[8;6] → [x;y]=inverse×[8;6] = [2; 1.33]

Example 2 (Rotation): Rotate point (1,0) by 90°
Solution: R=[cos90 -sin90; sin90 cos90]=[0 -1; 1 0] → [0 -1; 1 0][1;0]=[0;1]

Example 3 (Transform): Scale (2,3) by factor 2
Solution: S=[2 0; 0 2] → [2 0; 0 2][2;3]=[4;6]

Limits and Continuity

Definition of Limit

The limit of f(x) as x approaches a is L, written as: limx→a f(x) = L

This means: As x gets arbitrarily close to a (but not equal to a), f(x) gets arbitrarily close to L.

Limit Laws & Properties

  • Sum/Difference: lim[f(x) ± g(x)] = lim f(x) ± lim g(x)
  • Product: lim[f(x) · g(x)] = lim f(x) · lim g(x)
  • Quotient: lim[f(x)/g(x)] = lim f(x)/lim g(x), if lim g(x) ≠ 0
  • Power: lim[f(x)]n = [lim f(x)]n

Examples:

Example 1: limx→2(x²+3x) = 4+6=10

Example 2: limx→1[(x+2)(x-1)] = 3×0=0

Example 3: limx→3(x³-27)/(x-3) = limx→3(x²+3x+9)=27

Special Limits

  • limx→0 sin(x)/x = 1 (Important trigonometric limit)
  • limx→∞ (1 + 1/x)x = e (Definition of e)
  • limx→0 (ex - 1)/x = 1
  • limx→0 (ln(1+x))/x = 1

Examples:

Example 1: limx→0 sin(3x)/x = 3×limx→0 sin(3x)/(3x)=3×1=3

Example 2: limx→0 (e2x-1)/x = 2×limx→0 (e2x-1)/(2x)=2×1=2

Example 3: limn→∞ (1+1/n)n = e

Continuity

A function f is continuous at x = a if:

  1. f(a) is defined
  2. limx→a f(x) exists
  3. limx→a f(x) = f(a)

Types of Discontinuity:

  • Removable: Hole in graph (limit exists but f(a) undefined or different)
  • Jump: Left and right limits exist but are different
  • Infinite: Vertical asymptote

Examples:

Example 1: f(x)=(x²-1)/(x-1) has removable discontinuity at x=1

Example 2: f(x)=|x|/x has jump discontinuity at x=0

Example 3: f(x)=1/x has infinite discontinuity at x=0

Practical Examples

Example 1: Find limx→3 (x² - 9)/(x - 3)

Solution: Factor: (x-3)(x+3)/(x-3) = x+3 → limit = 6

Example 2: Is f(x) = 1/x continuous at x = 0?

Answer: No, infinite discontinuity (vertical asymptote).

Example 3: Find limx→∞ (2x²+3x)/(x²+5)

Solution: Divide numerator and denominator by x²: (2+3/x)/(1+5/x²)→2 as x→∞

Complex Numbers

Basics of Complex Numbers

Complex numbers extend real numbers to solve equations like x² + 1 = 0.

  • Imaginary Unit: i = √(-1), so i² = -1
  • Standard Form: z = a + bi, where a = real part, b = imaginary part
  • Conjugate: z̅ = a - bi (change sign of imaginary part)
  • Modulus/Absolute Value: |z| = √(a² + b²) (distance from origin)

Example: z = 3 + 4i has |z| = √(3² + 4²) = 5, conjugate = 3 - 4i

Operations with Complex Numbers

  • Addition: (a+bi) + (c+di) = (a+c) + (b+d)i
  • Subtraction: (a+bi) - (c+di) = (a-c) + (b-d)i
  • Multiplication: (a+bi)(c+di) = (ac-bd) + (ad+bc)i
  • Division: Multiply numerator and denominator by conjugate: (a+bi)/(c+di) = [(a+bi)(c-di)]/(c²+d²)

Examples:

Example 1: (2+3i)+(4-5i)=6-2i

Example 2: (1+i)(1-i)=1-i+i-i²=1-(-1)=2

Example 3: (3+4i)/(1+2i) = [(3+4i)(1-2i)]/(1+4) = (3-6i+4i-8i²)/5 = (11-2i)/5 = 2.2-0.4i

Polar & Exponential Forms

Polar Form: z = r(cos θ + i sin θ) where:

  • r = |z| = √(a²+b²) (modulus)
  • θ = arg(z) = tan⁻¹(b/a) (argument/angle)

Exponential Form: z = reiθ (Euler's formula: eiθ = cos θ + i sin θ)

De Moivre's Theorem: (cos θ + i sin θ)n = cos(nθ) + i sin(nθ)

Examples:

Example 1: Convert 1+i to polar
Solution: r=√2, θ=45° → √2(cos45°+i sin45°) = √2 eiπ/4

Example 2: Using De Moivre: (cos30°+i sin30°)³ = cos90°+i sin90° = i

Example 3: Find (1+i)⁸ using polar
Solution: 1+i = √2 eiπ/4 → (√2 eiπ/4)⁸ = (√2)⁸ ei2π = 16(cos2π+i sin2π)=16

Applications of Complex Numbers

  • Electrical Engineering: AC circuit analysis (phasors)
  • Quantum Mechanics: Wave functions are complex-valued
  • Signal Processing: Fourier transforms use complex exponentials
  • Fractals: Mandelbrot set uses complex iteration
  • Control Theory: Root locus analysis

Complex Roots of Equations

Every polynomial of degree n has exactly n complex roots (counting multiplicity).

Example: Find roots of x² + 4 = 0

Solution: x² = -4 → x = ±√(-4) = ±2i

Complex Conjugate Root Theorem: If a+bi is a root of a polynomial with real coefficients, then a-bi is also a root.

Examples:

Example 1: Roots of x³-1=0 are 1, (-1±i√3)/2

Example 2: If 2+i is root of x²-4x+5=0, find other root
Solution: By conjugate theorem: 2-i

Example 3: Solve x⁴+4=0
Solution: x⁴=-4=4(cosπ+i sinπ) → x=√2(cos(π+2kπ)/4 + i sin(π+2kπ)/4) for k=0,1,2,3

Sequences and Series

What are Sequences and Series?

A sequence is an ordered list of numbers following a specific pattern. A series is the sum of the terms of a sequence.

Example Sequence: 2, 4, 6, 8, 10, ... (even numbers)

Corresponding Series: 2 + 4 + 6 + 8 + 10 + ...

Types of Sequences

  • Arithmetic Sequence: Each term differs from the previous by a constant (common difference, d).

    Formula: an = a1 + (n-1)d

  • Geometric Sequence: Each term is multiplied by a constant (common ratio, r).

    Formula: an = a1 × r(n-1)

  • Harmonic Sequence: Reciprocals of an arithmetic sequence.
  • Fibonacci Sequence: Each term is the sum of the two preceding terms: 0, 1, 1, 2, 3, 5, 8, ...

Examples:

Example 1 (Arithmetic): 5, 9, 13, 17, ... find 10th term
Solution: a=5, d=4 → a₁₀=5+9×4=41

Example 2 (Geometric): 3, 6, 12, 24, ... find 8th term
Solution: a=3, r=2 → a₈=3×2⁷=3×128=384

Example 3 (Fibonacci): Find 9th Fibonacci number
Solution: Sequence: 0,1,1,2,3,5,8,13,21 → 9th term=21

Arithmetic Series Formulas

Sum of first n terms:

  • Sn = n/2 × [2a + (n-1)d]
  • Sn = n/2 × (a + l) where l = last term

Example: Find sum of first 10 terms: 3, 7, 11, 15, ...

Solution: a=3, d=4, n=10 → S10 = 10/2 × [2×3 + (10-1)×4] = 5 × [6 + 36] = 210

Examples:

Example 1: Sum first 20 natural numbers
Solution: a=1, d=1, n=20 → S₂₀=20/2[2×1+19×1]=10×21=210

Example 2: Sum 5+9+13+...+41
Solution: a=5, d=4, l=41. n=(41-5)/4+1=10 → S=10/2(5+41)=5×46=230

Example 3: If sum of first n terms is n²+2n, find 10th term
Solution: S₁₀=100+20=120, S₉=81+18=99 → a₁₀=S₁₀-S₉=21

Geometric Series Formulas

Sum of first n terms:

  • Sn = a × (rn - 1)/(r - 1) for r ≠ 1
  • Sn = a × (1 - rn)/(1 - r) for |r| < 1

Infinite Geometric Series (when |r| < 1):

  • S∞ = a/(1 - r)

Example: Sum of 2 + 1 + ½ + ¼ + ... (infinite)

Solution: a=2, r=½ → S∞ = 2/(1-½) = 4

Examples:

Example 1: Sum 3+6+12+...+192
Solution: a=3, r=2. Find n: 192=3×2ⁿ⁻¹ → 64=2ⁿ⁻¹ → n-1=6→n=7 → S₇=3(2⁷-1)/(2-1)=3(128-1)=381

Example 2: Sum 81+27+9+...+1
Solution: a=81, r=1/3. Find n: 1=81×(1/3)ⁿ⁻¹ → (1/3)ⁿ⁻¹=1/81=(1/3)⁴ → n-1=4→n=5 → S₅=81(1-(1/3)⁵)/(1-1/3)=121

Example 3: Infinite sum: 0.9+0.09+0.009+...
Solution: a=0.9, r=0.1 → S=0.9/(1-0.1)=0.9/0.9=1 (shows 0.999...=1)

Special Series Formulas

  • Sum of first n natural numbers: Σn = n(n+1)/2
  • Sum of squares: Σn² = n(n+1)(2n+1)/6
  • Sum of cubes: Σn³ = [n(n+1)/2]²

Example: Sum of squares from 1 to 5:

1² + 2² + 3² + 4² + 5² = 5×6×11/6 = 55

Examples:

Example 1: Sum 1+2+...+100
Solution: 100×101/2=5050

Example 2: Sum 1²+2²+...+10²
Solution: 10×11×21/6=385

Example 3: Sum 1³+2³+...+6³
Solution: (6×7/2)²=21²=441

Convergence and Divergence

  • Convergent Series: Sum approaches a finite limit (e.g., 1 + ½ + ¼ + ⅛ + ... = 2)
  • Divergent Series: Sum grows without bound (e.g., 1 + 2 + 3 + 4 + ...)
  • Tests for Convergence:
    • Geometric series test
    • Comparison test
    • Ratio test
    • Integral test

Examples:

Example 1: Σ(1/2ⁿ) converges to 1

Example 2: Σ(1/n) diverges (harmonic series)

Example 3: Σ(1/n²) converges to π²/6

Applications of Sequences & Series

  • Finance: Compound interest calculations (geometric series)
  • Physics: Harmonic motion, wave patterns
  • Computer Science: Algorithm analysis, time complexity
  • Engineering: Signal processing, Fourier series
  • Economics: GDP growth models, investment returns
