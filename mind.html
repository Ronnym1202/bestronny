Essential Trigonometry Rules

  • SOH: sin θ = Opposite / Hypotenuse
  • CAH: cos θ = Adjacent / Hypotenuse

Reading Graphs — Quick Tips

  • Gradient: Rise ÷ Run — pick two clear points on a straight line.
  • y-intercept: Where the graph crosses the y-axis (x = 0).
  • Roots / x-intercepts: Where the graph crosses the x-axis (y = 0).
  • Parabola vertex: The turning point of a quadratic curve.

Factorisation Methods

  • Trinomial (x² + bx + c): Find two numbers that multiply to c and add to b. Write as (x + p)(x + q).
  • Difference of squares (a² − b²): Always factors as (a + b)(a − b). Recognise this pattern instantly.
  • Check: Expand your answer mentally to verify — this takes 3 seconds and eliminates errors.

Core Calculus Rules

  • Power Rule (diff): d/dx[xⁿ] = nxⁿ⁻¹
  • Chain Rule: d/dx[f(g(x))] = f′(g(x)) · g′(x)
  • Product Rule: (uv)′ = u′v + uv′
  • Power Rule (integ): ∫xⁿ dx = xⁿ⁺¹/(n+1) + C  (n ≠ −1)
  • Integration by Parts: ∫u dv = uv − ∫v du

Key Matrix Formulas

  • 2×2 Determinant: det[[a,b],[c,d]] = ad − bc
  • 2×2 Inverse: A⁻¹ = (1/det A) × [[d,−b],[−c,a]]  (if det A ≠ 0)
  • Matrix Product (AB): Row of A · Column of B (dot product)
  • Characteristic Equation: det(A − λI) = 0 gives eigenvalues λ

Convergence Test Summary

  • Divergence: If lim aₙ ≠ 0, the series diverges immediately.
  • Geometric (∑arⁿ): Converges iff |r| < 1. Sum = a/(1−r).
  • p-Series (∑1/nᵖ): Converges iff p > 1.
  • Ratio Test: Compute L = lim|aₙ₊₁/aₙ|. Converges if L < 1.
  • Alternating (Leibniz): Converges if terms decrease monotonically to 0.
  • Integral Test: ∑aₙ and ∫f(x)dx share their convergence fate.

Complex Number Essentials

  • Arithmetic: (a+bi)+(c+di) = (a+c)+(b+d)i  |  use i² = −1 for multiplication
  • Modulus: |z| = √(a² + b²)
  • Argument: arg(z) = arctan(b/a), adjusted for quadrant
  • De Moivre: (cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ)
  • nth Roots of Unity: zₖ = e^(2πik/n) for k = 0, 1, …, n−1
